# LIBI Diamonds design system

The static `.dc.html` files in this project are the incumbent visual authority. The production implementation translates them into a responsive system; it does not replace their identity.

## Visual world

Quiet atelier precision. Product imagery lives on near-white catalogue fields; brand and story moments use deep teal satin photography. Graphite rules and type keep the experience exact, while antique gold is reserved for prices, emphasis, and high-intent actions.

## Tokens

- Ink `#141A1D`
- Ink soft `#454E52`
- Paper `#FCFCFA`
- Mist `#F2F5F4`
- Deep teal `#032F35`
- Antique gold `#987534`
- Gold light `#C9A96A`
- Rule `rgba(20, 26, 29, 0.16)`

Heebo is used from 200 through 600. Headings are light, tightly measured, and never decorative. Utility text is compact and slightly tracked. RTL layout uses logical properties throughout.

## Composition

Desktop uses a calm 12-column editorial grid with generous negative space. Mobile retains the supplied 393px rhythm and horizontal product/category rails. Product pages pair a large image gallery with a sticky configuration panel. No generic rounded-card grid, ornamental gradients, or invented luxury claims.

## Interaction

Primary commercial actions open a prefilled WhatsApp conversation. Controls have explicit hover, focus, selected, disabled, loading, error, and success states. Motion is limited to the mobile navigation reveal and image transitions, and is disabled by reduced-motion preferences.
